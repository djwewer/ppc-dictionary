# PPC Glossary Trainer

Статичний HTML/JS тренажер для вивчення термінів PPC (Google Ads) з режимом карток, тестом і трекінгом прогресу.

## Що всередині

Справжній багатосторінковий сайт (не SPA) — кожен крок це окрема HTML-сторінка з реальним редіректом:

- `index.html` — логін / створення профілю → редірект на `dashboard.html`.
- `dashboard.html` — вибір рівня, загальний прогрес.
- `level.html?level=1|2|3` — список термінів рівня, вибір режиму.
- `study.html?level=…` — картка на весь екран: клік перевертає, знизу кнопки "Знаю" / "Не знаю".
- `quiz.html?level=…` — тест з варіантами відповідей.
- `js/common.js` — спільна логіка (auth-guard, прогрес, сховище), підключається на кожній сторінці.
- `js/data.js` — словник термінів.

Словник термінів поділений на 3 рівні:
  1. **Обов'язково знати** — базові терміни для роботи PM з PPC.
  2. **Другий рівень** — розширений набір.
  3. **Можна залишити на потім** — решта глосарію.

Прогрес (скільки термінів засвоєно) зберігається в `localStorage` браузера, окремо на кожен профіль (ім'я + PIN). Захищені сторінки (`dashboard.html`, `level.html`, `study.html`, `quiz.html`) перевіряють сесію і редіректять на `index.html`, якщо вхід не виконано.

## ⚠️ Важливо про "логін + PIN"

Це **не справжня автентифікація**. Бази даних і бекенду немає — весь застосунок статичний. Логін + PIN — це лише спосіб розділити прогрес різних людей/профілів **в межах одного браузера**:

- Прогрес не синхронізується між пристроями чи браузерами.
- PIN зберігається у вигляді простого хешу в localStorage — це не захист від когось, хто має доступ до DevTools цього браузера.
- Якщо очистити дані сайту в браузері — весь прогрес зникне.

Якщо згодом захочеш кросплатформний прогрес — знадобиться мінімальна БД (Vercel KV / Postgres) або сторонній auth (Supabase/Firebase). Поточна версія свідомо цього уникає, як ти і просив.

## Деплой на Vercel через GitHub

1. Створи новий репозиторій на GitHub і запуш туди вміст цієї папки:
   ```bash
   git init
   git add .
   git commit -m "PPC glossary trainer"
   git branch -M main
   git remote add origin git@github.com:<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. Зайди на [vercel.com](https://vercel.com), "Add New… → Project", підключи цей репозиторій.
3. Framework Preset: **Other** (це статичний сайт, білд не потрібен). Build command і output directory можна залишити порожніми — Vercel сам роздасть файли з кореня.
4. Deploy. Готово — посилання вигляду `https://<project>.vercel.app` буде робочим одразу.

## Локальний перегляд

Будь-який статичний сервер підійде, наприклад:

```bash
npx serve .
```

і відкрий `http://localhost:3000`.
